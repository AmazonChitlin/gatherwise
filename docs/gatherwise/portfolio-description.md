# Gatherwise portfolio description

Gatherwise is a source-grounded AI event-readiness product built for an Arizona pilot. It helps organizers, vendors, and venues move from messy event details to a source-backed readiness summary without presenting unsupported legal certainty.

The product combines natural-language fact extraction, human review, deterministic rule evaluation, official evidence linking, grounded explanation, a Readiness Route, and an Event Change Simulator. The architecture is designed so AI can assist with structure and explanation while deterministic rules and official sources remain the authority.
