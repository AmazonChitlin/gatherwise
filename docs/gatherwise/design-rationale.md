# Gatherwise design rationale

## Chosen direction

The selected visual direction is **Local Signal**.

## Why it fits

- It feels closer to civic wayfinding and event logistics than generic AI branding.
- It supports the route metaphor without making the interface unfamiliar.
- It gives evidence tabs, status markers, and route stops a repeatable visual language.
- It keeps the showcase distinctive while preserving standard navigation, form, and disclosure behavior.

## Behavioral principle

Visual distinctiveness should not make the interface behave strangely. Gatherwise uses recognizable UI patterns and saves the product-specific language for evidence, route, and status concepts.
