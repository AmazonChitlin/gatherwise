# Gatherwise 90-second demo script

## Goal

Help a recruiter understand the problem, the product, the AI boundary, and Paul's contribution in about 90 seconds.

## Script

1. Open `/showcase`.
2. Start with the hero:
   Gatherwise is an Arizona-pilot event-readiness product that helps users move from messy event details to source-backed next steps.
3. Scroll to the tangled-problem section:
   explain that event readiness is fragmented across city, county, and state sources, and small event details can change what matters.
4. Show the hybrid-system section:
   AI can structure facts and explain results, but verified deterministic rules stay in charge of requirements and sources.
5. Move to the Readiness Route:
   point out how confirmed facts, requirement stops, missing information, and source anchors are connected.
6. Open the demo CTA and use a fictional scenario:
   show that the product can be explored without login and without permanent storage.
7. On results, call out:
   plain-language summary, evidence trail, official source links, and the change simulator.
8. Close with limitations:
   Arizona pilot, informational guidance, source-change risk, and human verification recommendation.

## Key line

If time is short, use:

> Gatherwise uses AI to help structure and explain event details, but deterministic rules and official sources remain the authority.
