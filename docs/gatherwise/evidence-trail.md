# Gatherwise Evidence Trail

## Pattern

Every expandable result follows the same compact sequence:

1. Your fact
2. Verified rule
3. Official source

The repetition is intentional. Users should not have to relearn how provenance works from card to card.

## What Each Step Shows

### Your fact

- Relevant event facts only
- User-facing state:
  - Confirmed
  - Needs review
  - Unknown
- Plain-language values

### Verified rule

- Rule ID
- Rule version token
- Matched conditions
- Unknown conditions

### Official source

- Source name
- Source ID
- Review date
- Direct source link

## Status Language

The current results interface uses prompt-approved labels:

- May apply
- Needs review
- Confirmed from your details
- Information missing
- Source needs review
- Not supported

## Results Hierarchy

The page now follows this order:

1. Plain-language readiness summary
2. Most important next action
3. Possible requirements
4. Missing information
5. Planning order
6. Evidence Trail
7. Full official sources
8. Limitations

## Notes

- Unknown facts remain unknown and are surfaced explicitly in both the missing-information section and the per-result trail.
- The Evidence Trail is expandable, but the core page still shows the most important summary and action without requiring expansion.
