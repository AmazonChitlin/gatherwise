# Gatherwise Known Limitations

- Gatherwise is an Arizona pilot, not a national product.
- The product provides informational readiness guidance, not legal advice or permit approval.
- Official source pages can change after review dates.
- Unsupported jurisdictions are refused rather than guessed.
- AI-backed extraction and explanation depend on server-side configuration and availability.
- The deterministic fallback path is strong enough for the public demo, but live-model quality still requires opt-in evaluation.
- Some internal code symbols and historical research docs still use older EventLocal naming.
- There is no dedicated lint script in the current repository.
- Browser-based accessibility validation is meaningful but not yet exhaustive across every assistive-technology and browser combination.
