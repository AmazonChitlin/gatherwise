# Gatherwise Affinity Mapping Template

## Board Setup

Create columns for:

- Hero understanding
- Intake-path choice
- Evidence trust
- Readiness Route comprehension
- Simulator comprehension
- AI boundary
- Accessibility observations
- Unexpected moments

## Note Format

Each note should include:

- Session code
- Task number
- Short observation
- Severity: low / medium / high
- Quote if consented

## Clustering Pass

1. Group repeated confusion points.
2. Group repeated trust wins.
3. Separate usability issues from content issues.
4. Tag accessibility-specific findings clearly.

## Output

- Top three recurring friction points
- Top three recurring trust signals
- One accessibility priority
- One hypothesis to strengthen
- One hypothesis to weaken
